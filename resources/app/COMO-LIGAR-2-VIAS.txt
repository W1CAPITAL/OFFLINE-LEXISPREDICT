LEXIS GABINETE v6.2 — COMO LIGAR A PLANILHA 2 VIAS + LOGIN POR USUÁRIO
=======================================================================

OBJETIVO: cada usuário loga com usuário/senha (validados NO SERVIDOR via
Apps Script). Você só vê os seus casos (coluna RESPONSAVEL); a aba
"Processos da empresa" mostra tudo (leitura). Dossiê sai em PDF.

PASSO 1 — ABA "Usuarios" (LOGINS E SENHAS)
  Na planilha crie uma aba chamada  Usuarios  com o cabeçalho exato:
     login | nome | senha | perfil | escritorio | ativo
   * login: minúsculas, sem espaço (ex: maria)
   * perfil: assistente / atendente / responsavel  (só afeta o rótulo)
   * escritorio: opcional
   * ativo: sim / nao
  As senhas são guardadas como HASH SHA-256 (não em texto puro). O jeito
  mais fácil de criar um usuário: no Apps Script, menu "Léxis" ->
  "Criar usuário (login/senha)" (pede login, nome e senha e já grava o hash).
  (Também dá para gerar o hash pelo navegador chamando o webhook com
   action=hash&senha=SUA_SENHA e colar na coluna senha.)

PASSO 2 — ABA DA CARTEIRA: COLUNA "Responsavel"
  Na aba principal (a que tem Protocolo), crie/renomeie a coluna:
     Responsavel
  Preencha-a com o LOGIN (ou o nome) do usuário DONO de cada processo.
  O desktop considera:
   - processo dele: Responsavel igual ao login/nome do usuário logado;
   - processo SEM Responsavel: aparece para todos (é um "pool" de casos
     sem dono — evita esconder registro de alguém);
   - os demais: ficam INVISÍVEIS para o usuário logado.
  A aba "Processos da empresa" mostra todos (leitura), como você pediu.

PASSO 3 — INSTALE O APPS SCRIPT (uma vez)
  1. Planilha -> Extensões -> Apps Script.
  2. Apague o código e cole o conteúdo de  LEXIS-SYNC-AppsScript.gs .
  3. Troque o TOKEN no topo por uma senha sua.
  4. Implantar -> Nova implantação -> "Aplicativo da web"
     -> Executar como: "Eu" -> Acesso: "Qualquer pessoa" -> Implantar.
  5. Copie a URL /exec e o TOKEN para o desktop (Configurações).

PASSO 4 — CONFIGURE O DESKTOP
  Abra o Lexis Gabinete.exe -> Configurações:
   - "URL da planilha"  : link do Google Sheets (usado SÓ como fallback)
   - "URL do webhook"   : URL /exec
   - "Token"            : o mesmo TOKEN do script
   - "Seu nome"         : aparece em atendido_por / editado_por
  Clique "Testar webhook" (ok:true) e FECHE e REABRA o app: vai aparecer
  a tela de LOGIN. Entre com usuário/senha criados no PASSO 1.

SEGURANÇA (leia)
 - A leitura NÃO usa mais o CSV público: o desktop chama action=list com o
   token de sessão e o servidor devolve SÓ os casos dele (minhas) + um
   resumo "todas" usado pela aba Processos da empresa.
 - action=write recusa linhas cujo Responsavel não é o solicitante.
 - Sessão expira em 8h e renova a cada sync.
 - Recomendado: compartilhe a planilha apenas com VOCÊ, não "qualquer
   pessoa com o link" (controle de acesso = o webhook).

COMO FUNCIONA (ações do webhook)
  auth  -> valida login/senha, devolve token de sessão
  list  -> devolve minhas (só as suas) + todas (para a aba empresa)
  write -> grava; valida que cada linha é do seu responsavel
  ping  -> teste do botão "Testar webhook"
  auto  -> revalida sessão ao abrir o app

OFFLINE: sem internet, as edições vão para uma fila local (outbox) e são
enviadas quando você clicar "Sincronizar". O botão "Entrar em modo local"
permite usar sem servidor (sem separação por usuário).
