Por que não copiamos as chaves

No Vercel, variáveis marcadas como Sensitive não podem ser lidas de volta. Este programa também não as guarda. O caminho é o login que você já usa.

1

Você abre o Lexis Gabinete neste computador

É só a janela. Não há arquivo .env nem chave colada no disco.

2

Você entra com o mesmo usuário de sempre

A sessão fica nos cookies, como no navegador — não no arquivo do EXE.

3

O servidor Vercel usa as chaves e devolve o resultado

Evolution, Supabase, DataJud e scripts rodam lá. O desktop só mostra a tela.

Salesforce, HubSpot e a maioria dos CRMs enterprise usam o mesmo modelo: o cliente nativo é uma casca; a operação e os segredos ficam no servidor.
